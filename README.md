# Mind-Map-Software

This is my final year university project.
I created this because I had always found mind maps confusing and took the opportunity to learn how they work
and try and create software for mind map creation that worked better for how my mind works
Full details on reasoning, planning, the literature review to decide on features, and code explanation can
be found in the report pdf

## Built with
- Java, JavaFX,  Maven

## Features
- Create, edit and delete lines and arrows
- Create, edit and delete shapes
- Add text to lines and shapes
- Save and load to/from files
  
## Running It
1) fork and clone the repository
2) Install Java
3) Install Maven
4) mvn compile
5) mvn exec:java

May also work if packaged into a .jar file, that was not tested.
